## 1. ゴールと完了条件

記録の候補（課題・タスク）を、既存の管理項目と照らし合わせてカードで確かめ、新規・更新・関連・却下・保留を選び、選んだものだけで変更計画を作る。計画は管理ファイルの変更後の内容と差分、ハッシュを含み、画面で確かめられる。**管理ファイルにはまだ書かない**（F）。

**完了条件**（23 章）: AT-09・11・12・14 に合格。変更計画を出力して確認できる。

| 試験 | 内容 | E での確かめ方 |
|---|---|---|
| AT-09 | 「やらない」「未完了」「金曜かも」「担当不明」 | Phase D の評価セットの結果に加え、候補カードで要確認の目印・終端状態への遷移が個別確認になること（自動テスト） |
| AT-11 | 候補の一部だけ承認、記録だけ承認 | 計画に選んだ候補だけが入り、未承認の候補と管理ファイルが変わらない（自動テスト＋画面） |
| AT-12 | 同文再送、同音声再処理、承認ボタン連打 | 適用台帳（session＋analysis revision＋candidate id）と根拠の照合で、同じ候補が二度計画に入らない。承認の連打は同じ承認を返す。同名別件を手動で新規にできる（自動テスト） |
| AT-14 | 追記専用の既存項目更新候補 | 自由文を置換せず提案として保存。新規の追記だけが計画に入る（自動テスト） |

## 2. 作るもの

### E1 Core: 管理項目と重複照合

- `ManagementItem`（11.1 の項目。内部 ID・表示 ID `ISS-000001` / `TSK-000001`・kind 別の状態の集合・revision）、`ItemEvidence`
- `TitleSimilarity`: 12.2-3 の正規化（NFKC・前後空白・連続空白・英字の大小だけ）と、タイトルの文字 2-gram Dice 係数、本文のキーワード共通度、スコア `0.65×タイトル + 0.25×本文 + 0.10×project`。タイトルが 2 文字未満なら曖昧
- `DuplicateFinder`: 明示 ID の確認（不存在・別 kind はエラー候補）→ 正規化タイトルの完全一致 → 類似の上位 5 件。担当・期限・状態・否定・数値の違いを別に返す。スコアを「同一の確率」と表示しない

### E2 Core: レビューの判断と変更計画

- `CandidateDecision`: 新規・既存へ更新・関連だけ・却下・保留、編集後の値、親課題、対象の既存項目
- 個別確認の規則（12.3・13.2）: 完了・取消・再開・期限変更・担当変更・競合は「すべて選択」の対象外
- `ChangePlanner`: 承認した判断から、項目の後の状態（snapshot）、管理ファイルの後の内容（11.5 の管理ブロックで描画）、ファイルごとの before / after ハッシュ、17 章の計画 JSON（canonical な直列化と `plan_hash`）を作る。追記専用のファイルでは更新を提案に回す（AT-14）
- 承認の失効（13.3）: 候補本文・根拠の文字起こし・対象 ID・旧 Revision・ファイルハッシュのどれかが変われば無効

### E3 Infrastructure: DB とファイル

- マイグレーション 4: `items`・`item_evidence`・`managed_files`・`item_bindings`・`approvals`・`apply_batches`・`apply_file_ops`・`item_versions`・`candidate_applications`・`audit_events`、表示 ID の採番（再利用しない）
- 計画の保存: `Workspace\transactions\<batch-id>\plan.json` と、変更後のファイルの中身（staged blob）・snapshot。DB の `approvals` / `apply_batches`（状態 `planned`）

### E4 App: 画面

- 「管理」タブ: UI-08 候補カード（種別・新規/更新/言及・タイトル・根拠・既存の候補・旧値→新値・保存先・警告）、UI-09 最終確認（ファイルごとの unified diff・件数・警告）、UI-10 管理一覧（F で項目が入るまでは空）
- 反映ボタンは F まで無効にし、「変更計画を保存」だけを有効にする

## 3. 進め方

E1 → E2 → E3 → E4 の順に、各段で自動テストを書いて区切りごとにコミットする。E の評価は、Phase D の評価セットの記録から候補を作り、重複照合の閾値と AT-11・12・14 を自動テストで確かめる。
