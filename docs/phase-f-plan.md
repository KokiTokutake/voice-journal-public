| 判断 | 既定にした内容 | 理由 |
|---|---|---|
| 対象のファイル | ワークスペースの中の `management\issues.md` / `tasks.md` だけ（ローカル NTFS） | 14.1。利用者に既存の管理ファイルはない |
| 置換の方法 | 同じフォルダーの一時ファイルに書いて Flush・再読込で検証し、`File.Replace`（Win32 `ReplaceFile`）で置き換え、置換直前の内容を退避ファイルに残す。新規作成は `FileMode.CreateNew` | 14.1・14.2-6。退避の実体も before hash と照合する |
| 排他 | ワークスペースごとの名前付き Mutex と、対象ファイルを共有なし（`FileShare.None`）で開いて照合 | 14.1 |
| 途中で止まったバッチ | 起動時と反映の前に、14.3 の表で判定する。すべて before なら再開、すべて after なら DB だけ確定、混在なら前進完了、どれでもないなら RecoveryRequired で止める | 14.3 |
| 取消 | 反映済みのバッチの before snapshot へ戻す新しい変更計画を作り、通常の承認・反映を通す。後から手で編集された項目は戻さず、競合として示す | 14.4 |
| DB のマイグレーション前のバックアップ（AT-24） | 適用前に SQLite Online Backup API で `backups\db-<日時>.db` を作る | 14.4 |
