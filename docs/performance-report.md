# 性能の報告（NFR-01〜12）

- 根拠: 詳細仕様書 20 章（NFR）・23 章（Phase G の完了条件「性能報告」）
- 作成: 2026-11-08。各 Phase の報告書の測定値を集め、足りないものを測り足した
- 判定の方針: 懸念が残る項目は合格にしない（2026-11-06、利用者の指示）

## 測定の環境

| 項目 | 値 |
|---|---|
| CPU / GPU | AMD Ryzen AI 9 HX 375（12 コア 24 スレッド）/ Radeon 890M（内蔵） |
| メモリ | 32 GB（測定中の空きは 9〜10 GB。Chrome などほかのアプリも動いていた） |
| OS | Windows 11 Home（ビルド 26300）、画面の倍率 125% |
| 文字起こし | whisper.cpp（CPU）、small、VAD あり、ゲインあり |
| 記録の作成 | 同梱の llama-server b12121（Vulkan）＋ Gemma 4 E2B（Q4_0、MTP あり）、C=16384、O=6144 |

## 利用者にお願いする測定

1. NFR-03: 録音を開始してから「録音中」になるまでの時間（マイク・PC 内部音声・両方）
2. NFR-01: LAN を切って「録音 → 文字起こし → 記録の作成 → 管理の反映」を通す（AT-22）
3. NFR-12: ナレーターで録音の状態とエラーが読まれるか、画面の倍率 150/200%（AT-25）
4. NFR-11: 利用者のワークスペースでの復元訓練（できれば別の PC で）
5. NFR-04: 実機での両方 8 時間の録音（AT-05）

## 判断をお願いすること

- NFR-07: 区間ごとの出力を減らす（AT-08 の品質と引き換え）か、基準を見直すか
- NFR-05: エンジンを起動する条件を約 8.5 GB に上げるか
